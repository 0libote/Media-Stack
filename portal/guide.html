Get your apps talking.

Start with Jellyfin. Add the library tools when you’re ready. Each app keeps its own account and settings.

1. Give Jellyfin a library

Open Jellyfin, choose a language and create your administrator account. Add a Movies library at /data/media/movies and a Shows library at /data/media/tv.

Files go in your chosen data folder on the server, under media/movies or media/tv. Jellyfin can read your library but cannot delete the media files through this install.

2. Set up movies and shows

Open Radarr and Sonarr. Create a login in each app. In Settings → Media Management, add the root folders below. Enable hardlinks instead of copying when available.

AppRoot folder
Radarr/data/media/movies
Sonarr/data/media/tv

Import an existing library with Library Import. Choose a quality profile that fits your storage and connection.

3. Add search with Prowlarr

Open Prowlarr, create a login and add the indexers you use. In Settings → Apps, add Radarr and Sonarr with Full Sync.

  • Prowlarr server: http://prowlarr:9696
  • Radarr server: http://radarr:7878
  • Sonarr server: http://sonarr:8989

Get each app’s API key from its Settings → General page. Test each connection before saving. Keep these keys private.

4. Connect downloads (optional)

This step needs the VPN downloads option enabled during setup. See docs/downloads.md in the repository to add it later. Without it, skip this step and use your existing library.

On the server, run docker compose logs qbittorrent to find the temporary password. Open qBittorrent, sign in as admin, and immediately set a permanent password in its Web UI settings.

  • Default save path: /data/torrents
  • Incomplete downloads: /data/torrents/incomplete
  • Create category movies with save path /data/torrents/movies.
  • Create category tv with save path /data/torrents/tv.
  • In Advanced settings, select tun0 as the network interface. Gluetun uses this for the VPN tunnel.

In Radarr and Sonarr, go to Settings → Download Clients and add qBittorrent with host gluetun, port 8080, and your qBittorrent login. Use category movies for Radarr and tv for Sonarr. Test and save. Keep completed download handling enabled.

The apps share the same paths, so no remote path mapping is needed. A working VPN connection is required for qBittorrent to start.

5. Make requests with Seerr

Open Seerr, choose Jellyfin and connect to http://jellyfin:8096. Sign in with your Jellyfin administrator account and sync your libraries.

Add Radarr at http://radarr:7878 and Sonarr at http://sonarr:8989 using their API keys. Select the root folders from step 2, quality profiles, and a default server for each. Set the external Jellyfin URL to the address you use in your browser.

Try one request for media you’re allowed to download. With downloads configured, check it reaches the right app, finishes in qBittorrent, imports into your library, and appears in Jellyfin.

Which address goes where?

In your browser, use your server’s address and the app’s port. When connecting one app to another, use the service names shown above. localhost inside a container means that container.

Keep this stack on a trusted home network. Complete the account setup before sharing access. The portal lists links; it does not check whether an app is running. Downloads, if enabled, use the VPN; the other apps use your normal connection.
